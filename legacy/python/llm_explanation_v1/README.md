# Python LLM explanation v1

Pipeline lịch sử tạo explanation từ Explanation IR v1 bằng template. Artifact liên quan nằm trong `data/reports/llm_explanations/` và các manifest `llm_explanation_manifest_*`.

Module này không còn active vì pipeline hiện hành bắt đầu từ evidence package 2.1 và dùng TypeScript narrative. Dependency cũ được giữ nguyên để đọc provenance; active code không import module này.
