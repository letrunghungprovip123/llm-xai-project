# Domain glossary

- **Stage definition:** Git-managed declaration of one executable pipeline unit.
- **Pipeline run:** One requested execution spanning one or more stage runs.
- **Stage run:** One attempt to execute one stage definition.
- **Artifact:** Immutable package of files plus a manifest and stable identity.
- **Release:** Governed selection of verified artifacts intended for consumption.
- **Gate:** Structured acceptance result with expected and observed values.
- **Certified:** Accepted under the applicable release policy and evidence.
- **Ready with limitations:** Blocking technical gates pass while an explicit
  scientific limitation remains.
- **Conceptual section:** Research-content responsibility frozen before dashboard implementation.
- **Physical page:** Runtime route that may consolidate multiple conceptual sections.
- **Operational metadata:** Mutable status, approval, audit and query indexes.
- **Analytical truth:** Frozen metrics and conclusions from certified artifacts.
- **Lineage edge:** Directed parent-child relationship between artifacts.
- **Provider-dependent stage:** Stage requiring an external paid or probabilistic model provider.
